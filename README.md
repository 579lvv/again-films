# A’GAIN · 气味与日常

A minimal showcase of two AIGC films: coffee scented candle and botanical room spray.

Public page: https://579lvv.github.io/again-films/

Static HTML, CSS and JavaScript; no build step, third-party fonts or tracking.
GitHub Pages publishes the `main` branch root. The two H.264/AAC MP4 files retain
the supplied films' resolution, frame rate and sound, with web encoding and
fast-start playback. Original source videos are kept unchanged locally.

Desktop displays two films side by side; mobile stacks them. Playback uses native
browser controls. Starting one film pauses the other.
